# 03 · 听力：从"听懂"到"记住"

> 你的描述："听懂了但反应不过来，听懂了下一句记不得上一句，整段基本都听懂了
> 但记不得讲了啥。"
>
> **这是一个非常明确的症状，成因也非常明确：你在做实时翻译。**

---

## 一、诊断：为什么"听懂了却记不住"

工作记忆（working memory）容量大约 **4 个信息块**，而且**一次只能干一件事**。

你现在听英语的流程是：

```
英语声音 → ① 识别单词 → ② 译成中文 → ③ 理解中文 → ④ 存中文进记忆
                          ↑
                     这一步吃掉 70% 的工作记忆
```

结果：第 ② 步（翻译）占满了处理资源，第 ④ 步（存储）没有余量。
所以你**每一句都听懂了，但每一句都没存下来**——听完整段，记忆是空的。

**注意这和"听不懂"是完全不同的问题**，不要用"听不懂"的方法（背单词、
反复精听）去治它。你需要治的是**流程**：

```
目标流程：
英语声音 → ① 意群识别 → ② 直接理解（不经中文） → ③ 挂到结构锚点上
```

三个动作，对应三套训练：**去译码**、**意群化**、**结构预听**。

---

## 二、训练一：去译码（Shadowing 影子跟读）

**这是唯一能真正切断"英→中"回路的训练。** 优先级最高。

### 为什么有效
跟读时你的嘴在忙，**大脑没有空闲资源做翻译**。被迫绕过中文直接处理声音。
连续做 3-4 周，"不翻译也能懂"的通路就建立起来了。

### 三个阶段

| 阶段 | 做法 | 每天 | 周次 |
|---|---|---|---|
| **同步跟读** | 看着文本，和音频同时读，追上语速 | 10 min | W1-2 |
| **延迟跟读** | 看着文本，落后音频 2-3 个词 | 10 min | W3-5 |
| **盲跟读** | **不看文本**，落后 3-5 个词跟读 | 10 min | W6+ |

⚠️ **盲跟读是核心**，前两阶段只是脚手架。第 6 周必须过渡到盲跟。

### 材料（按难度递进）
- W1-4：六级真题听力（长对话 + 讲座），语速 1.0x
- W5-8：六级真题 1.25x + TED 短演讲
- W9-12：雅思听力 Section 3-4（学术讨论，语速快、信息密）+ BBC 6 Minute English

### 执行细节
- **必须出声**，默读无效（默读时大脑仍会翻译）
- 不追求跟准每个词，**追求不断气**。断了就跳到下一个意群接上
- 语调、重音要模仿——这会顺带给雅思口语打底
- 同一段材料**跟读 3 遍就换**，不要磨到滚瓜烂熟（那变成背诵了，无效）

## 三、训练二：意群化（Chunking）

**你现在是按"词"听的，要改成按"意群"听。** 意群 = 一口气说完的 3-7 个词。

一句话按词听是 20 个信息块（记不住），按意群听是 4 个信息块（刚好装得下）。

```
按词听（20 块，溢出）：
The / researchers / found / that / the / new / drug / reduced /
symptoms / in / about / sixty / percent / of / patients / within /
just / two / weeks

按意群听（4 块，装得下）：
[The researchers found] [that the new drug reduced symptoms]
[in about 60% of patients] [within just two weeks]
```

### 训练方法：断句标记

```
① 拿一段听力文本（60-90 秒）
② 一边听，一边在文本上用 / 标出说话人的自然停顿
③ 对照：你划的停顿和说话人的停顿是否一致
④ 然后按你划的意群朗读，模仿那个节奏
```

每天 1 段，10 分钟。做 2 周你会发现停顿位置**极其规律**：
基本落在**从句边界、介词短语边界、主谓之间**——**和 01 号文件里的断点信号
完全是同一套东西。**

📌 **这是长难句训练和听力训练的汇合点**：纸上会切分从句 = 耳朵上会切分意群。
这就是你说的"一石二鸟"真正生效的地方。

---

## 四、训练三：结构预听 + 复述（直接治"记不得讲了啥"）

### 4.1 结构预听：只记锚点，不记全文

一段 3 分钟的讲座，你**不可能也不需要**记住所有内容。
考点永远落在**结构位置**上。听的时候只抓 3-5 个锚点：

| 锚点 | 信号词 | 一定会出题 |
|---|---|---|
| **主题句** | Today I'd like to / My focus is on | ★★★ |
| **分点标志** | First / Another / Finally / Now let's turn to | ★★★ |
| **转折** | However / But the problem is / That said | ★★★ |
| **因果** | because / as a result / which explains why | ★★☆ |
| **举例** | for instance / take X as an example | ★☆☆（例子本身少考，例子证明的观点常考） |
| **强调/对比** | in fact / unlike / by contrast / the key point | ★★★ |
| **结论** | so / in short / the upshot is | ★★★ |

**心法**：听的时候，脑子里维护的不是"句子"，而是一个**目录**：
```
主题：X 有问题
 ① 原因 A
 ② 原因 B ← 这里有个 however，作者其实不同意 B
 结论：应该做 C
```
**这个目录只有 5 行，工作记忆装得下。** 而你现在试图装 30 行句子，必然装不下。

### 4.2 复述训练（Retelling）—— 最直接的解药

这是治"整段听懂但记不得"的**核心训练**，每天必做。

```
① 听 60-90 秒（一次，不暂停，不看文本）
② 立刻用【英文】说出 3 句话：主题 / 2 个要点 / 结论
③ 录下自己说的
④ 看文本，对照漏了什么
⑤ 记录："漏在哪个位置"——是开头？转折后？还是例子后？
```

**第 ⑤ 步是关键。** 两周后你会发现漏的位置高度规律，通常是：
- 转折后（because 一 however 就重新分配注意力，前面的丢了）
- 数字/专名出现后（处理数字花了资源）
- 长句出现后（回到译码模式了）

知道自己漏在哪，就能**针对性地在那个位置提前警觉**。

⚠️ **必须用英文复述。** 用中文复述等于承认翻译流程，白练。
一开始说得很烂很卡是正常的，第 3 周会顺。

### 4.3 什么时候做听写（Dictation）

**听写不是主力训练，是补漏工具。** 只在下面两种情况用：

1. 复述时发现某句**完全没听到**（不是没记住，是没听见）→ 那一句听写 5 遍
2. 连读/弱读导致的误听（`want to → wanna`、`a lot of → alotta`）→ 专项听写

**不要拿整篇做听写。** 整篇听写 30 分钟只能治"听不清"，
而你的问题是"听清了记不住"——完全打偏。

## 五、每日听力流程（40 分钟）

```
① 影子跟读        10 min   去译码（最高优先级，绝不跳过）
② 意群断句标记    10 min   W1-4 做，W5 后可减到每周 3 次
③ 复述训练        15 min   听 90s → 英文复述 → 对照 → 记漏点
④ 补漏听写         5 min   只针对复述中"没听到"的句子
```

### 三个加速器（第 5 周起加入）

1. **变速训练**：1.25x 练 → 1.0x 考。1.0x 会感觉"慢得能思考"，这个余量就是分数。
   ⚠️ 不要超过 1.5x，过快会退回"抓关键词猜"的模式，反而破坏意群化。
2. **口音扩容**（为雅思铺路）：W7 起每周 2 次英音（BBC）+ 1 次澳音，
   六级只有美音+英音，但雅思有澳/新/南非。
3. **无字幕看剧**：每周 1 集（40min）美/英剧，**关全部字幕**。
   不查词、不暂停，只训练"在信息缺失下保持理解"的耐受力。
   这对雅思 L8.5 很关键。

## 六、六级听力的应试补充（W9 起）

前面是能力训练，这部分是考试技巧，**能力没到之前做技巧是浪费时间**，
所以放在第 9 周。

- **读题窗口**：六级每段之间有读题时间，训练"15 秒扫 4 题、圈出题干关键词"，
  带着预期去听。这能把工作记忆负担降一半。
- **同义替换意识**：正确选项**几乎不会**原词复现。听到的 `cut back on spending`
  对应选项 `reduce expenditure`。W9-12 每套真题后，
  专门整理"原文表达 → 选项表达"的替换对，累积 100 对。
- **首尾句权重**：讲座题的第一题几乎必在开头 30 秒，最后一题必在结尾 30 秒。
  这两段注意力拉满。
- **听到就选，不回看**：六级听力最大的失分来源是"纠结上一题，丢了下一题"。
  **定死规则：题目过了就过了，绝不回头。** 这一条能直接救 10-15 分。
