# 04 · 写作与翻译：最大的分数缺口

> 你需提升的 140 分里，**65 分在这一块**（130 → 195，占 46%）。
> 而你的自我诊断完全没提到它——这是最需要纠正的认知偏差。
>
> 好消息：写作翻译是六级里**最可控、最可预测**的一块。
> 题型固定、话题有限、评分标准公开。**它是唯一可以靠储备直接买分的板块。**

---

## 一、六级写作翻译的评分真相

### 写作（106 分）
阅卷是**印象分 + 挡位制**。老师平均 40 秒看一篇。决定挡位的是：

| 权重 | 因素 | 你能做什么 |
|---|---|---|
| 30% | **结构清不清楚**（能否 10 秒看出几段几个论点） | 固定模板，段首句必须是论点句 |
| 30% | **句式有没有变化**（全是简单句 = 及格档天花板） | 句式库，见下 |
| 25% | **用词准不准、有没有档次** | 话题语料库 |
| 15% | 语法错误、拼写、字数 | 定点检查清单 |

📌 **关键洞察**：你已经在练长难句了。**长难句训练的产出应该直接变成写作句式库。**
一个能拆解三层嵌套的人，写出带一个定语从句 + 一个状语从句的复合句是自然的事——
**但前提是你练过"写"，而不只是"读"。**（这就是 01 号文件第六节"一句四用"里
③回译 ④仿写 存在的原因。）

### 翻译（106 分）
汉译英，段落，5 句左右。评分**按扣分制**：

- 漏译一个信息点：扣分（最严重）
- 主谓结构错误：扣分
- 时态/单复数/冠词：小扣，但累积起来很致命
- 用词不地道但意思对：不扣或小扣

📌 **所以翻译的第一原则是：宁拙勿巧。**
保证信息全、主谓对、时态一致，**不要为了"高级"冒险用不熟的结构**。
你从 61% 到 92% 靠的不是华丽，是**零硬伤**。

## 二、翻译：五步流程（每篇都走）

```
① 断句      把中文按"一个主谓一句"切开，中文常把 3 个意思塞一句
② 定主干    每句先确定英文的 主语 + 谓语（这一步决定 60% 的成败）
③ 挂修饰    定语后置（of / 定从 / 分词）、状语位置
④ 查五点    时态 / 单复数 / 冠词 / 介词 / 主谓一致
⑤ 数信息点  回读中文，逐个确认没漏
```

### 演示

```
中文：中国的高铁网络在过去十年间迅速扩张，如今总里程已超过四万公里，
      位居世界第一，极大地改善了城乡之间的交通联系。
```

**① 断句**（中文一句 = 英文 2-3 句）
```
/ 高铁网络过去十年迅速扩张
/ 如今总里程超四万公里，位居世界第一
/ 极大改善了城乡交通联系
```

**② 定主干**
```
句1: China's HSR network  expanded
句2: the total length  exceeds     （"位居世界第一"处理成同位语或分词，不另起主句）
句3: 主语选谁？→ 用前句的扩张做主语 → This (expansion) has improved
     或者合并到句1，用分词状语：..., greatly improving...
```

**③ 挂修饰 + ④ 查五点**
```
China's high-speed railway network has expanded rapidly over the
past decade.                          ← over the past decade → 现在完成时 ✔
Its total length now exceeds 40,000 kilometres, the longest in the
world, greatly improving transport links between urban and rural areas.
      ↑ 同位语处理"世界第一"        ↑ 分词状语处理"改善"
```

**⑤ 数信息点**：高铁网络✔ 过去十年✔ 迅速扩张✔ 总里程✔ 四万公里✔
世界第一✔ 改善✔ 城乡✔ 交通联系✔ → **9 个全在。**

### 中译英的五个高频硬伤（你的 130 分大概率栽在这里）

| 硬伤 | 错 | 对 |
|---|---|---|
| **无主句直译** | 随着经济发展 → With economy develop | With the development of the economy / As the economy develops |
| **动词连用** | 政府决定加强管理 → The government decided strengthen | decided **to** strengthen |
| **时态混乱** | 过去十年 + 一般过去时 | over the past decade → **现在完成时** |
| **中式主语** | 我的家乡发生了很大变化 → My hometown happened big changes | My hometown **has undergone** great changes |
| **冠词/单复数** | 大学生应该… → College student should | College student**s** should |

📌 **④ 查五点这一步，每次都要真的走。** 六级翻译扣的分 70% 是这五类低级错误，
不是"不够高级"。**修完这五类，翻译分立刻上一个台阶。**

## 三、写作：结构模板 + 句式库

### 3.1 万能议论结构（四段，背死）

```
【段1 · 引入 + 立场】3 句
  ① 现象/背景句
  ② 争议句：Opinions are divided on whether...
  ③ 立场句：In my view, ... （明确站一边，绝不骑墙）

【段2 · 论点一】4 句
  ① 论点句（段首，必须是全段最短最清楚的一句）
  ② 解释：why
  ③ 例证：for instance（具体，可以是编的，但要像真的）
  ④ 小结回扣论点

【段3 · 论点二 或 让步反驳】4 句
  ① Admittedly, 对方有理的部分
  ② However, 为什么仍不足以推翻我的立场
  ③ 论证
  ④ 小结

【段4 · 结论】2 句
  ① 重申立场（换词，不重复段1原句）
  ② 升华/建议句
```

字数：六级要求 150+，**写到 200-230 最优**。太少显得空，太多必然出错。

### 3.2 句式库：12 个必须练到肌肉记忆的骨架

**这 12 个句式来自你长难句训练里拆过的结构。**
每周挑 3 个，用当周话题各造 5 句，12 周正好轮 4 遍。

```
1  同位语从句作主语
   The assumption that X can solve Y overlooks the fact that Z.

2  what 引导主语从句
   What makes this trend alarming is not its speed but its irreversibility.

3  not...but... 平行
   The real problem lies not in the lack of resources but in their misallocation.

4  倒装强调（Only / Not until）
   Only when individuals take responsibility will collective change follow.

5  it 形式主语 + that
   It is widely acknowledged that technological progress has outpaced regulation.

6  分词状语（前置/后置）
   Confronted with mounting competition, firms are forced to innovate.
   ..., thereby reducing the burden on public services.

7  定语从句嵌套（一层就够，别炫技）
   Students who lack the guidance that experienced mentors provide often
   struggle to define their goals.

8  让步 + 转折
   While the short-term costs are undeniable, the long-term gains far outweigh them.

9  虚拟语气
   Had the policy been introduced a decade earlier, the crisis might
   have been averted.

10 比较结构
   The more accessible information becomes, the harder it is to
   distinguish fact from opinion.

11 独立主格
   Resources being limited, priorities must be set.

12 抽象名词作主语（让句子瞬间显得成熟）
   The failure to address these concerns risks eroding public trust.
```

⚠️ **考场上一篇文章用 4-6 个不同句式就够了**，其余用干净的简单句。
全篇长难句 = 必出语法错误 = 掉档。**变化 ≠ 复杂。**

### 3.3 话题语料库（必须提前建，考场攒不出来）

六级话题就那么几类。每类准备 **10 个词组 + 2 个论点 + 1 个例子**：

| 话题 | 频率 |
|---|---|
| 教育（大学教育目的、通识 vs 专业、终身学习） | ★★★ |
| 科技（AI、社交媒体、隐私、自动化与就业） | ★★★ |
| 个人发展（时间管理、挫折、目标、自律、合作） | ★★★ |
| 环境与可持续（低碳、消费主义） | ★★☆ |
| 文化与传统（传统技艺、文化自信、全球化） | ★★☆ |
| 城市与社会（老龄化、城乡差距、公共服务） | ★★☆ |

**语料卡格式**：
```
话题：AI 与就业
词组：automate routine tasks / displace low-skilled labour /
      reskilling programmes / augment rather than replace /
      productivity gains / the digital divide
论点1：AI 消灭岗位的同时创造新岗位，关键在转型速度
论点2：受冲击最大的是最缺转型资源的群体 → 需公共干预
例子：ATM 普及后银行柜员没消失，转向了销售与咨询岗
```

📌 **一个例子可以复用到多个话题。** 准备 8 个"万能例子"
（一个技术变革、一个个人挫折、一个政策效果、一个文化保护……），
就能覆盖绝大多数题目。

## 四、雅思写作的差异（W9 起了解，考完六级再正式练）

| | 六级 | 雅思 |
|---|---|---|
| 篇数 | 1 篇 150+ 词 | Task1 图表 150+ ＆ Task2 议论 250+，共 60 分钟 |
| 评分 | 印象挡位 | 四项独立打分：TR / CC / LR / GRA |
| 最大差异 | 模板加分 | **模板扣分**（Coherence 要求真实逻辑衔接） |
| 立场 | 明确即可 | 必须**全篇一致**且**回应题目每一部分** |

⚠️ **重要警告**：六级的四段模板拿到雅思会**压分到 6.0-6.5**。
雅思 W7 要求段落之间有真实的论证推进，不是"First / Second / In conclusion"。

所以：**六级期间照用模板（它在六级里有效）**，但从 W5 起，
每篇作文额外练一个动作——**把模板痕迹词换成实质衔接**：

```
❌ Firstly, ... Secondly, ...
✅ The most immediate consequence is ... A less visible but more
   durable effect, however, is ...
```
这个习惯养成后，雅思转轨会省掉一个月。

Task 1（图表描述）是全新技能，六级考完再学，两周足够——它高度套路化。

## 五、每周写作翻译流程

```
每周 2 次翻译     每次 1 段（5 句），走完五步流程，自批 + 记硬伤类型
每周 1 篇作文     45 分钟限时写完
每周 1 次精修     把上周的作文重写一遍（这一步最提分，绝不能省）
每周 3 个句式     用当周话题各造 5 句
每周 1 张语料卡   补一个话题
```

### "重写"为什么是最关键的动作

第一遍写是**输出你现有的水平**，重写是**安装新水平**。
只写不改，12 周后你还是原来的水平写了 12 篇。

重写流程：
```
① 自批：只标三类问题 —— 语法硬伤 / 句式单调 / 论证跳跃
② 对照 04 号文件的句式库，把 2-3 个简单句升级
③ 整篇重抄一遍（手写或打字），让新句式过一遍手
④ 把这次的硬伤记进错误日志
```

📌 12 周 × 1 篇精修 = 12 篇你**真正会写**的文章，
其中的句式和语料考场直接调用。这是 65 分缺口最实在的来源。
