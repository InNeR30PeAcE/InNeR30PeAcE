# 06 · 每日模板、错误日志与打卡表

---

## 一、每日时间模板

### 标准日（工作日，95 分钟）

| 时段 | 分钟 | 内容 | 备注 |
|---|---|---|---|
| 1 | 10 | **影子跟读** | 最先做，此时大脑最清醒；出声 |
| 2 | 30 | **长难句一句四用** ×3 句 | 拆 → 听写 → 回译 → 仿写 |
| 3 | 15 | **复述训练** | 听 90s → 英文复述 → 对照 → 记漏点 |
| 4 | 10 | 意群断句 / 补漏听写 | 二选一 |
| 5 | 15 | **语境卡片** | 新卡 6 张 + Anki 复习 |
| 6 | 15 | 写作或翻译 | 每周 3-4 天安排，其余日跳过 |

### 最小日（20 分钟，忙到不行时的底线）
```
跟读 10min  +  长难句 1 句走完四用 10min
```
**这两件事断线三天，前面的积累会明显回退。其他都可以断。**

### 周末日（1 天 3 小时）
```
① 完整模考 / 真题套刷      130 min
② 复盘（错因归类、语料收集） 50 min
```

## 二、错误日志（核心资产，比刷题重要）

建一个文件 `english/log/错误日志.md`，四类分开记，每类只记一行。

### 2.1 长难句日志

```
| 日期 | 句子片段 | 我的切分 | 正确切分 | 错因(1-5) |
|------|---------|---------|---------|----------|
| 09/15 | ...the data collected last year showed... | 把 collected 当谓语 | collected 是分词定语，showed 才是谓语 | 1 |
```

**错因编码**（只用这五个，不要新增）：
```
1 = 谓语判断错（非谓语当谓语 / 漏数）
2 = 省略没发现（that / 关系代词 / 连词+主语+be）
3 = 主谓被隔开，找错主语
4 = 并列结构对不上（not...but / both...and / rather than）
5 = 特殊结构（倒装 / 强调 / 比较 / 虚拟）
```

### 2.2 听力漏点日志

```
| 日期 | 材料 | 漏了什么 | 漏点位置 | 原因 |
|------|-----|---------|---------|------|
| 09/16 | CET6-2023-12-讲座1 | 第二个论点整段 | however 之后 | 转折时注意力重置 |
```

**漏点位置编码**：
```
A = 开头（还没进入状态）
B = 转折后（however / but）
C = 数字/专名之后
D = 长句之后（退回翻译模式）
E = 结尾（注意力已耗尽）
```

### 2.3 熟词生义收集

直接进 Anki，但**每周在日志里写一行统计**：
```
W3：新增 42 张 | 复习正确率 78% | 最常错类型：动词化的名词
```

### 2.4 写作翻译硬伤日志

```
| 日期 | 我写的 | 应该写 | 硬伤类型(1-5) |
|------|-------|-------|--------------|
| 09/17 | With economy develop... | As the economy develops... | 1 |
```

**硬伤编码**：
```
1 = 无主句直译      2 = 动词连用（缺 to / 缺 and）
3 = 时态错          4 = 中式主语
5 = 冠词/单复数/主谓一致
```

### 2.5 每 4 周统计一次（这是日志唯一的用途）

```
W4 统计示例：
长难句错因： 1=3次  2=11次  3=8次  4=2次  5=1次
  → 主错因是 2（省略）和 3（主谓隔开），W5-8 专项打这两类

听力漏点：  A=1  B=9  C=4  D=6  E=2
  → 主漏点是 B（转折后）→ 训练"听到 however 立刻在心里写下前半句的结论"

翻译硬伤： 1=2  2=1  3=7  4=4  5=12
  → 5（冠词单复数）压倒性第一 → 每篇翻译交卷前专门扫一遍冠词和复数
```

📌 **不统计的日志是垃圾。** 记日志的唯一目的是四周后拿到这三行数字，
然后把训练时间重新分配。

## 三、13 周打卡表

复制到 `english/log/打卡.md`，每天打勾。
每周五列必须都有勾才算完整周；允许每周 1 个"最小日"。

```
图例： ● 完成   ◐ 最小日   ○ 断线

周次 | 一 二 三 四 五 六 日 | 跟读 长句 复述 卡片 写译 | 本周复盘
-----|---------------------|---------------------------|----------
W1   |                     |                           |
W2   |                     |                           |
W3   |                     |                           |
W4   |                     |                           | ★阶段复盘
W5   |                     |                           |
W6   |                     |                           |
W7   |                     |                           |
W8   |                     |                           | ★半程模考
W9   |                     |                           |
W10  |                     |                           |
W11  |                     |                           |
W12  |                     |                           | ★目标 630+
W13  |                     |                           | ★考试
```

### 断线规则（重要）

- 断 1 天：正常，第二天补最小日即可
- 断 2 天：**第三天必须做满标准日**，不要"算了这周废了"
- 断 3 天以上：**退回上一周的强度重启 2 天**，不要直接跳回当周进度
  （尤其是盲跟读，断线后直接盲跟会挫败）

📌 **不要追补欠下的量。** 断了就断了，从今天继续。
追补会把训练变成任务，任务感是这类长周期计划最大的杀手。

## 四、每周五分钟自检（周日晚）

问自己三个问题，答案写一行：

1. **这周有没有一句长难句是我"拆解完但没有回译/仿写"的？**
   （只拆不用 = 只在加固你最强的阅读，白费）
2. **这周复述的时候，有没有一次是用中文想好了再翻成英文说的？**
   （那是翻译，不是复述，白练）
3. **这周有没有一篇作文是写完就扔的？**
   （精修才提分，写完就扔 = 12 周后还是原水平）

三个问题任一答"有"，下周把那件事的优先级提到最高。
