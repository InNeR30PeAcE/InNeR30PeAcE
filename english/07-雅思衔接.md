# 07 · 雅思衔接（六级考完后启动）

> 原则：**六级期间不分心练雅思**，只保留一件维持性动作（口语自说自话）。
> 六级考完（12 月中）→ 休息 3 天 → 启动 8-10 周雅思专项。

---

## 一、能力复用地图

| 六级已建立的 | 雅思直接复用 | 复用率 |
|---|---|---|
| 数谓语定层级法 | R 长难句、TFNG 判断、W 句式 | **100%** |
| 影子跟读 / 去译码 | L 全部，S 流利度 | **100%** |
| 意群化 + 结构预听 | L Section 3-4 | **95%** |
| 熟词生义语境卡 | R 同义替换、W 用词 | **90%** |
| 议论逻辑 + 语料库 | W Task 2、S Part 3 | **70%**（要去模板化） |
| 六级作文模板 | ❌ **会压分**，必须弃用 | 0% |
| 六级应试技巧 | ❌ 题型完全不同 | 0% |

**结论：你花在长难句和听力流程上的 13 周，在雅思上一分不浪费。**
这就是你说的"一石二鸟"真正成立的部分。

---

## 二、8.0 的分数结构

雅思 overall 8.0 的现实组合（均值 ≥7.75）：

| 组合 | L | R | W | S | 均值 | 难度评估 |
|---|---|---|---|---|---|---|
| A（推荐） | 8.5 | 8.5 | 7.0 | 7.0 | 7.75 → **8.0** | 最可行 |
| B | 9.0 | 8.5 | 7.0 | 6.5 | 7.75 → **8.0** | 口语弱者可行 |
| C | 8.0 | 8.0 | 7.5 | 8.0 | 7.875 → **8.0** | W/S 要求过高，不推荐 |

**战略结论**：
- **L 和 R 是拉分项**，要冲 8.5-9.0。这两块和六级高度同源，你有基础。
- **W 7.0 和 S 7.0 是保底项**，也是**真正的瓶颈**——中国考生 W 卡 6.5 极普遍。
- 不要试图把 W 冲到 7.5 来救 L/R，性价比极低。**把 L/R 做到 8.5 便宜得多。**

## 三、四项的具体缺口和打法

### Listening → 8.5（错 ≤ 5 / 40）
六级听力 220 分 ≈ 雅思 L 7.0-7.5。到 8.5 还差三样：

1. **拼写零容错**：填空题拼错 = 错。专项训练：地名、人名、日期、数字、
   常见学术词的听写拼写。**这是最廉价的提分点，两周能提 0.5**。
2. **口音扩容**：澳音（元音偏移：day→die 感）、新西兰音、南非音。
   六级完全不考，必须单独练 2 周。
3. **Section 4 单人长讲座**：6 分钟无停顿，考连续注意力。
   → 直接沿用 03 号文件的**结构预听 + 复述**，材料换成 Section 4。

### Reading → 8.5（错 ≤ 5 / 40）
六级阅读 235 分 ≈ 雅思 R 7.5。缺口在**速度和题型**，不在理解力：

1. **时间压力**：3 篇 2700 词 + 40 题 / 60 分钟。六级从容，雅思不从容。
   → 训练定时：每篇 18 分钟硬切。
2. **TFNG（True/False/Not Given）**：中国考生最大失分点。
   **核心就是长难句精读** —— False 和 Not Given 的区别往往藏在一个
   限定词、一个比较结构、一个情态动词里。**你练的数谓语定层级法正对这个题型。**
3. **Matching / 段落信息定位**：靠同义替换敏感度，沿用语境卡片资产。

### Writing → 7.0（真正的瓶颈）
**必须去模板化。** 具体三件事：

1. **Task 2 的段落要有真实论证推进**，不是"First/Second"。
   → 每段内部：论点 → 机制（为什么会这样）→ 让步或后果 → 回扣。
   "机制"这一环是 6.5 和 7.0 的分界线。
2. **Task Response 要回应题目的每一部分**。
   雅思题目常有两问（"To what extent do you agree" + "What measures..."），
   漏答一问直接封顶 6.0。→ 动笔前必须在卷上圈出"要回答几个问题"。
3. **Task 1 图表**：全新但高度套路，2 周搞定。
   四类图（趋势线/柱状/饼/流程图 + 地图）各背一套描述框架 + 数据比较句式。

### Speaking → 7.0（六级期间就要起步）
**六级期间唯一的雅思动作**：每周 2 次，每次 10 分钟。

```
做法：随机抽一个 Part 1 话题，对着手机录音说 2 分钟，不准备、不停顿、
      不重来。说完听回放，只记一件事：卡在哪里。
目的：不是提高水平，是【不让口语从零起步】。
      六级考完启动雅思时，你已经有 26 次开口经验，不会一开口就崩。
```
影子跟读顺带训练了语调和连读，这部分口语基础已经在打了。

## 四、六级考完后的 8 周雅思计划（框架，到时细化）

| 周 | 主线 |
|---|---|
| W1-2 | 题型认知 + 一套完整模考定位真实分数；Task 1 四类图框架；澳音起步 |
| W3-4 | R 定时训练 + TFNG 专项；L 拼写专项 + Section 4；W Task 1 每周 3 篇 |
| W5-6 | W Task 2 去模板化（每周 2 篇 + 精修）；S Part 2 计时 2 分钟专项 |
| W7 | 全真模考 ×2，按考试节奏；S 模拟面试 |
| W8 | 定点补漏 + 考前维持 |

⚠️ 雅思成绩 2 年有效。**确认你的留学申请时间线后再定考试日期**——
太早考会过期，太晚考赶不上申请截止。这个时间点你告诉我，我把日期倒排。

## 五、需要你提供的信息（用于细化雅思部分）

1. 目标入学时间（哪一年秋季 / 春季入学）
2. 申请的项目类型（硕士？什么方向？）→ 决定是否需要 Academic 单项小分要求
3. 是否有单项最低要求（很多项目要求 W ≥ 6.5 或 7.0，比 overall 更卡人）
