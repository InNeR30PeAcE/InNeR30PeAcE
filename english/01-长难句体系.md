# 01 · 长难句体系：数谓语定层级法

> 这是整个课程的核心。你"砍句子砍乱了"的根本原因是：**用语感找边界**。
> 语感是模糊判断，嵌套两层还行，三层必错。下面这套方法用**可数的客观标志**
> 代替语感，砍完还能**自检对不对**。

---

## 一、方法总览：五步法

```
① 数谓语       → 确定句子里有几个"分句"
② 数连接词     → 用公式自检切分是否完整
③ 框主干       → 找出唯一的主句 SV(O)，其余全部降级
④ 递归         → 对每个从句重复 ①②③
⑤ 回读         → 用中文说出主干一句话，再挂修饰
```

### 核心公式（你的自检工具）

```
谓语动词个数 − 连接手段个数 = 1
```

"1" 就是那个唯一的主句。如果算出来不是 1，说明你**漏了省略**：

| 差值 | 说明 | 去找什么 |
|---|---|---|
| = 1 | ✅ 切分完整 | — |
| > 1 | 少找了连接手段 | 省略的 that / 省略的关系代词 / 省略的 if / 分号 |
| < 1 | 多算了连接手段 | 把介词误当关系词 / 把 to do、-ing 误当谓语 |

**这个公式就是你缺的那个"自检机制"。** 以后砍句子不靠感觉，靠算。

---

## 二、第①步：数谓语 —— 最关键的一步

只有**谓语动词（finite verb）**才能撑起一个分句。必须先训练到能瞬间区分：

### 是谓语（有时态/人称/数）
- 一般式：`fails`、`shift`、`argued`
- 完成/进行/被动：`have embraced`、`is being replaced`、`had begun`
- 情态 + 动词：`can survive`、`must be`
- be + 表语：`is wishful thinking`

### 不是谓语（非谓语，不能单独成句）
| 形式 | 例子 | 它的真实身份 |
|---|---|---|
| to do | `to adapt`, `to have been done` | 不定式：目的/定语/主宾语 |
| -ing | `shifting`, `having finished` | 分词/动名词：定语/状语/主宾语 |
| -ed（无助动词） | `a method **used** by...` | 过去分词：定语/状语 |
| 名词化的动词 | `the **retreat** of glaciers` | 名词 |

⚠️ **最容易错的两个陷阱**

1. **-ed 形式的歧义**：`The data collected last year showed...`
   `collected` 看着像谓语，其实是过去分词定语；`showed` 才是谓语。
   **判断法**：一个分句里只能有一个谓语；若两个 -ed 并排且中间无连接词，
   前一个必是分词。
2. **被动的助动词才是谓语核心**：`is required`、`was thought to be`
   ——整体算**一个**谓语，不是两个。

### 专项练习（Week 1 每天 10 句）
拿到任何长句，先只做一件事：**用铅笔圈出所有谓语，写下个数**。
不理解意思也要能圈对。这一步准确率不到 95% 之前，不要练后面的步骤。

## 三、第②步：数连接手段

四类，共同点是**每一个都引出一个从句/分句**：

| 类别 | 成员 | 引出 |
|---|---|---|
| **从属连词** | that, whether, if, because, although, while, since, unless, as, so that, before/after/when/until | 名词从句 / 状语从句 |
| **关系词** | who, whom, whose, which, that, where, when, why | 定语从句 |
| **连接代词/副词** | what, whoever, however, how, why（引导名词从句） | 名词从句 |
| **并列连词** | and, but, or, yet, so（连接两个**对等**分句时才算） | 并列分句 |

### 三种高频省略（差值 > 1 时就去这里找）

```
① that 省略（宾语从句 / 同位语从句）
   I think ∅ he is right.
   the fact ∅ they had begun retreating...

② 关系代词省略（仅限从句中作宾语时）
   the book ∅ I bought yesterday
   ⚠️ 作主语时不能省：the book that arrived ✅（that 不可省）

③ 状语从句的"连词+主语+be"省略
   When ∅ ∅ asked about it, he refused.  (= When he was asked...)
   Although ∅ ∅ expensive, it sells well.
```

⚠️ **不算连接手段的**（这是你"多算"的来源）：
- 介词短语：`in which` 算（in + which，which 是关系词），但单纯 `in the market` 不算
- and 连接两个**名词或动词短语**时不算：`bread and butter`、`came and went`
  ——只有 and 两侧各有一个完整谓语时才算连接分句

## 四、第③步：框主干 + 降级

**降级（chunking）是对抗工作记忆溢出的关键动作。**

做法：把每一个从句、介词短语、分词结构，在脑子里**压缩成一个词**，
用一个占位符替代。

```
原句：
The idea that a company which fails to adapt to the technologies
that its competitors have already embraced can survive in a market
where consumer expectations shift monthly is, frankly, wishful thinking.

降级后：
The idea [X] is wishful thinking.
```

主干就出来了：**"这个想法是空想。"** 剩下的 [X] 是"什么想法"，
可以之后慢慢展开。

**关键心法**：读长句时，你的目标**不是从左到右理解每个词**，
而是**先拿到骨架，再往上挂肉**。读到 `The idea that...`，立刻预判：
"后面一长串都是解释 idea 的内容，我要去找 idea 的谓语"，
然后**跳读**到 `is`。

### 断点信号（train your eyes to see these）

眼睛扫到这些符号，立刻在心里打一个 `/`：

```
高优先断点：  ,  ;  —  (  )    关系词  从属连词
中优先断点：  and/but/or 后跟完整句
低优先断点：  介词（of/in/with/for/by/to）   分词（-ing/-ed）
```

### 插入语：直接跳读
逗号—逗号、破折号—破折号、括号之间的内容，**第一遍读的时候直接跳过**。

```
The researchers, who had spent six years in Antarctica, concluded that...
→ The researchers concluded that...
```
主谓被插入语隔开是最常见的"读断气"原因。跳读后主谓立刻贴在一起。

## 五、完整演示：三个层级递增的例子

### 例 1：定语从句嵌套（你说的"从句套从句"典型）

```
The idea that a company which fails to adapt to the technologies
that its competitors have already embraced can survive in a market
where consumer expectations shift monthly is, frankly, wishful thinking.
```

**① 数谓语**：`fails` / `have embraced` / `can survive` / `shift` / `is` → **5 个**
**② 数连接**：`that`(同位语) / `which`(定从) / `that`(定从) / `where`(定从) → **4 个**
**③ 自检**：5 − 4 = 1 ✅

**④ 分层**（缩进表示嵌套深度）：
```
L0 主句:  The idea [同位语从句] is wishful thinking.
 L1 同位语:  that a company [定从] can survive in a market [定从]
   L2 定从1:  which fails to adapt to the technologies [定从]
     L3 定从2:  that its competitors have already embraced
   L2 定从3:  where consumer expectations shift monthly
```

**⑤ 回读**：
> 主干：这个想法是空想。
> 展开：一家公司，如果不去采用竞争对手早已采纳的技术，还想在一个消费者
> 期待每月都变的市场里活下去——这种想法是空想。

📌 **这里的关键技术动作**：`can survive` 的主语是 `a company`，它俩被
`which fails...embraced`（整整 11 个词）隔开。**如果你没有先框定
`a company ... can survive` 这个骨架，读到 `can survive` 时就会不知道谁 survive。**
这就是你说的"砍乱了"。

---

### 例 2：带省略 + 名词从句作主语

```
What surprised the researchers was not the speed at which the glaciers
retreated but the fact they had begun retreating decades earlier than
current models predicted.
```

**① 数谓语**：`surprised` / `was` / `retreated` / `had begun` / `predicted` → **5 个**
**② 数连接**：`What` / `at which` / `than` → **3 个**
**③ 自检**：5 − 3 = 2 ≠ 1 ❌ → **差值 > 1，去找省略！**

找到了：`the fact ∅ they had begun` —— 同位语从句的 `that` 被省略。
补上后连接手段 = 4 个，5 − 4 = 1 ✅

**④ 分层**：
```
L0 主句:  [主语从句] was not A but B.       ← not...but... 是并列表语
 L1 主语从句:  What surprised the researchers
 L1 表语A:  the speed [定从: at which the glaciers retreated]
 L1 表语B:  the fact [同位语: (that) they had begun retreating
                       [比较从句: earlier than current models predicted]]
```

**⑤ 回读**：
> 主干：让研究者惊讶的不是 A，而是 B。
> 展开：不是冰川退缩的速度，而是它们开始退缩的时间比现有模型预测的早了几十年。

📌 **两个技术动作**：
- `not A but B` 是**并列**，A 和 B 结构对等（都是 the + 名词 + 修饰）。
  看到 `not` 就要预期 `but`，这是**预判式阅读**。
- `was not the speed ... but the fact ...` 中间隔了一个定语从句，
  如果不预期 `but`，读到 `but` 会以为是转折，方向就反了。

---

### 例 3：倒装 + 分词 + 双重否定（六级压轴 / 雅思阅读难句）

```
Only when the subsidies were withdrawn did it become clear that the
industry, long praised as a model of efficiency, could not have
survived without the support it had consistently denied receiving.
```

**① 数谓语**：`were withdrawn` / `did become` / `could not have survived` /
`had denied` → **4 个**
（`praised` 是过去分词定语，`receiving` 是动名词，都不算）
**② 数连接**：`when` / `that` / `the support ∅ it had denied`（省略关系代词）→ **3 个**
**③ 自检**：4 − 3 = 1 ✅

**④ 分层**：
```
L0 主句:  did it become clear [that...]      ← Only when 开头引起部分倒装
 L1 状语:  Only when the subsidies were withdrawn
 L1 that从句:  the industry (插入语) could not have survived without the support
   L2 插入语:  long praised as a model of efficiency   ← 分词短语，跳读
   L2 定从:  (which) it had consistently denied receiving
```

**⑤ 回读**：
> 主干：只有当补贴被撤销，才清楚地看出……
> 展开：这个长期被誉为效率典范的行业，离开它一直否认自己接受过的那笔支持，
> 根本活不下来。

📌 **三个技术动作**：
- `Only + 状语` 置句首 → **主句部分倒装**（`did it become`）。看到句首 Only/Not until/
  Hardly/Never，立刻预期倒装，别把 `did` 当实义动词。
- `long praised as...` 前后都有逗号 → **插入语，第一遍跳读**，主语 `the industry`
  和谓语 `could not have survived` 立刻贴合。
- `denied receiving` = 否认接受过。`without the support it had denied receiving`
  是双重绕：它否认接受过 → 但其实接受了 → 没有它活不下来。**这种地方要把
  逻辑方向单独写下来验算**，别在脑子里过。

## 六、每日训练流程（30 分钟，雷打不动）

### 一句四用（Week 1 起执行）

选 **3 个长难句**（来源见下），每句走完四步：

```
① 拆解（5min/句）  纸上写：谓语数、连接数、自检公式、缩进分层、中文主干
② 听写（3min/句）  把句子录成音频或用 TTS 读出来，不看原文听写
                   → 直接训练"长句的听觉解析"
③ 回译（4min/句）  只看自己写的中文，翻回英文，再与原文逐词对比
                   → 直接训练翻译 + 写作句式
④ 仿写（3min/句）  用原句的骨架换话题造一个新句
                   → 把"认识"变成"会用"
```

**为什么必须四步走完**：第①步只提升阅读（你最强的一块）。
②③④ 分别打向听力、翻译、写作——你真正缺分的三块。
**只做①是本课程最容易犯的错，等于把 140 分的缺口只往 25 分的方向砸。**

### 语料来源（按周次推进）

| 周次 | 来源 | 难度 |
|---|---|---|
| W1-2 | 六级真题**阅读**长句（自己标出全篇最长的 3 句） | ★★☆ |
| W3-4 | 六级真题**翻译**参考译文的英文句 + 六级听力**长句题干** | ★★☆ |
| W5-8 | 雅思阅读原文（剑桥真题 12-19）+ The Economist 段落 | ★★★ |
| W9-12 | 六级真题全篇 + 雅思阅读 True/False/Not Given 的长句 | ★★★ |

📌 **W3-4 开始就加入听力语料**——因为你的听力问题需要的是"长句实时解析"，
在纸面上练熟了必须搬到耳朵上。

## 七、错误日志（必须建，见 06 号文件）

每次砍错都记一行：

```
日期 | 原句片段 | 我砍成了什么 | 正确切分 | 错因分类
```

**错因只分五类**（分类越少越有用）：
1. 谓语判断错（把非谓语当谓语 / 漏数）
2. 省略没发现
3. 主谓被隔开，找错主语
4. 并列结构对不上（not...but / both...and / A rather than B）
5. 特殊结构（倒装 / 强调 / 比较 / 虚拟）

**4 周后统计频次**：你的错误一定高度集中在其中 1-2 类。
到那时候，把 80% 的长难句时间只投在那 1-2 类上。这比现在盲目练更有效率。
